# Supplier-to-Sales Data Platform

## Overview

An end-to-end Data Engineering project that ingests
supplier product data and retail sales transactions,
validates and transforms the data, and prepares it
for reliable storage and analytics.

## Objectives

- Ingest data from multiple sources.
- Identify and handle data-quality issues.
- Store data in PostgreSQL.
- Build reliable, testable data pipelines.
- Progressively extend the architecture to AWS.

### SQL Analysis

Performed exploratory SQL analysis using PostgreSQL to investigate:

- Revenue distribution by country.
- Monthly revenue trends.
- Top products and services by revenue.
- Top customers by revenue.
- Monthly invoice volume and average order value.

Detailed queries and findings are documented in [`docs/sql-analysis.md`](docs/sql-analysis.md).
